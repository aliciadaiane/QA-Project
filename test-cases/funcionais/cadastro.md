# Casos de teste - Funcionalidade de Cadastro

Implementar a funcionalidade de cadastro de usuário com campos para entrada de email e senha. Os usuários preencherão essas informações e, em seguida, serão registrados no sistema. A validação será realizada para garantir que os campos sejam preenchidos corretamente.

Para o cadastro de novo usuário, ele não pode ter um email já cadastrado no sistema. 
A senha precisa ter 8 ou mais dígitos.
